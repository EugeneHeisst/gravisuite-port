# Gravitation Suite PORT

Local unofficial port of Gravitation Suite 3.1.1 (SeNtiMeL / Chocohead) to Minecraft 1.21.1 / NeoForge 21.1.256, for IndustrialCraft 2 PORT. Work in progress. Original reference is retained under gitignored `related/`.

Build: `./build.sh`. Test worlds and version archives are isolated from the installed game. No publication or deployment has been performed.
